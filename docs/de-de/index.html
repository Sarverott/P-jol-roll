    P_JOL_ROLL - Dokumentation¶

    Polnisch Journals of Laws Ressourcen operativen lurker Loader - Komplexe Reihe von Tools zum Umgang mit Datamining, Crawling und Parsing aller Gesetzesdokumente, die von der polnischen Regierung veröffentlicht wurden nationales Gesetzbuch, Paket von genehmigten Rechtsakten oder verfügbare Verfassungsversion

    Die Idee¶

    Jede Handlung, die in Dziennik Ustaw (seit 1918) und Monitor Polski (seit 1930), vom Freien genommen ELI API von Sejm und im Freien gehalten: rohe Dateien in einem Eimer, Tabellen und markdown in einem Datensatz auf Hugging Face. Jede Datei kann gegen ihre Prüfsumme überprüft werden, jede Handlung ist an die Handlungen gebunden, die sie ändert, an die Arbeit von Sejm, die sie gemacht hat, und an die Urteile, die sie anwenden. Das ferne Ziel ist ein kleines Model und ein Agent, der alles liest: eine offene Teufelsfürsprecher für jeden Menschen (Vision).

    Nicht (formal) Rechtsberatung. Siehe Was die Daten sind und was nicht.

    Agenten¶

    .agents/ ist die eigene Domain der Agenten: Leute lesen es, Agenten schreiben es. Anmerkungen halten ihre Erkenntnisse, Ideen was als nächstes gebaut werden könnte und Dinge zu überprüfen was auf eine Entscheidung wartet oder nicht verifiziert wurde. Sicht ist ein persönliches Kapitel und ist nur für alle außer seinem Autor lesbar.
