    Installation¶

    Was Sie brauchen¶

    Ding Warum
    Node.js 24 oder neuer, npm 11 oder neuer Alles läuft darauf (der Code ist TypeScript, laufen mit) tsx); .nvmrc sagt 24, engines in package.json sagt dasselbe
    Git Klonen; das Repository hat ein Submodul, das Obsidian-Plugin
    ca. 1 GB Diskette Abhängigkeiten und der Camoufox Browser, der npm install Downloads für checkup
    Aufgabe, fakultativ kürzere Befehle. Eine Kopie kommt mit den Abhängigkeiten: npx task

    Disk für die Daten ist eine separate Angelegenheit: siehe wie groß es ist.

    Stufen¶

    git clone --recurse-submodules https://github.com/Sarverott/P-jol-roll.git
cd P-jol-roll
npm install
task verify

    npm install auch den Browser herunterladen ()camoufox-js fetch) und richtet die Git Hooks (Husky) ein. task verify führt den Biome-Check, den Build und die Tests aus. Die Tests fragen nichts im Internet.

    Dann versuchen Sie eine kleine Versammlung:

    task gather -- 2026 --acts --limit 5

    Es schreibt die Listen und die Auflistung von 2026 in resources/dataset/ und die Akten von fünf Akten in resources/bucket/.

    Ohne Aufgabe¶

    Jede Aufgabe ist ein npm Skript darunter:

    Mit Aufgabe ohne
    task gather -- 2026 npm run gather -- 2026
    task checkup -- 2026 npm run checkup -- 2026
    task resources:plan -- dataset npm run hub -- plan dataset
    task verify npx biome check && npm run build && npx vitest run

    Token für Hugging Face¶

    Nur das Senden von Daten braucht es. Das Lesen von öffentlichen Repositories nicht.

    echo "HF_TOKEN=hf_..." > .env

    .env wird von Git ignoriert. Das Token benötigt Schreibzugriff auf die in resources/.map.json. siehe Hugging Face.

    Einstellungen aus der Umwelt¶

    Aufgaben lesen sie von .env auch der Arbeitskopie (eine in der Shell gesetzte Variable gewinnt).

    Variabel Ausfall Was es verändert
    ELI_API https://api.sejm.gov.pl/eli wo gather fragt. Tests zeigen es auf eine lokale Kopie
    RESOURCES_DIR resources Wo alles geschrieben und gelesen wird
    HF_TOKEN nicht Token für hub push und für private Repositories
    SEJM_API, SAOS_API Die echten Adressen Das gleiche für sejm und saos
    CRAWLEE_STORAGE_DIR storage Wo der Browser von checkup hält seine Schlange, während es läuft. Die Sammler halten ihre im Gedächtnis

    Das Obsidian Gewölbe¶

    Das Repository ist auch ein Obsidian-Tresor: Öffnen Sie sein Verzeichnis in Obsidian, um die Dokumente mit Links zu lesen. .obsidian/plugins/hefaisto ist ein separates Repository ()Sarverott/hefaisto. Nichts beim Sammeln hängt davon ab.
