    Funkcje¶

    Każda funkcja projektu i każdy jego sposób działania - napisane przez task functions:map z katalogu (src/core/catalog/procedures.ts), więc nie edytuj go ręcznie. Wyrzutnia (goła task), jego REPL oraz task do oferują każdą funkcję; inne sposoby, gdzie komórka nazywa jak. Funkcja zapisu (support) jest uruchamiana przez przeglądarkę i api tylko na tej maszynie, kiedy api działa z --allow-writing (aplikacja pulpitu tak), każdy po "tak" osoby; gospodarz publiczny pokazuje, że jest wyłączony (Q19). – to dziura.
