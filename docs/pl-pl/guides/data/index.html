    Dane¶

    Wszystko zebrało ziemie. resources/W dwóch miejscach z dwoma miejscami pracy.

    resources/
├── dataset/                    tables: small, read often
│   ├── lists/
│   │   ├── index.json          what the API offers, with addresses
│   │   ├── publishers.json     journals with their years and counts of acts
│   │   ├── statuses.json       every status an act can have
│   │   ├── document_types.json every type of act (Ustawa, Rozporządzenie, ...)
│   │   ├── reference_types.json every kind of tie between acts
│   │   ├── keywords.json
│   │   └── institutions.json
│   ├── acts/<journal>/<year>.jsonl        metadata, one act per line
│   ├── files/<journal>/<year>.jsonl       checksum and source of every gathered file
│   ├── details/<journal>/<year>.jsonl     details of acts, put together by compile
│   ├── references/<journal>/<year>.jsonl  ties between acts, one per line
│   ├── texts/<journal>/<year>.jsonl       which markdown was made from which HTML
│   ├── texts/<journal>/<year>/<address>.md  the text as markdown
│   └── checkups/<journal>/<year>.jsonl    what the browser saw, one visit per line
└── bucket/                     raw files of every act
    └── <journal>/<year>/
        ├── <address>.json              details
        ├── <address>.references.json   ties to other acts
        ├── <address>.pdf               the published text
        ├── <address>.html              the text as HTML, for some acts
        ├── <address>.struct.json       parts, chapters, articles of the HTML text
        └── <address>.T.pdf, .U.pdf     other texts of the act

    Tabele files, details, references oraz texts są opisane w od plików surowych do tabel i tekstów. Praca z Sejm i wyroki sądowe mają własne katalogi: patrz inne źródła.

    <journal> en DU lub MP. <address> jest identyfikatorem, który API daje na każdy akt, na przykład WDU20260000001.

    Jak nazywa się akt¶

    Nazwa Przykład Używane
    ELI DU/2026/1 adresy API: dziennik, rok, stanowisko
    adres WDU20260000001 nazwy plików; identyfikator używany przez ISAP
    wyświetlacz Dz.U. 2026 poz. 1 jak prawnicy to cytują

    Stare akty mają również wiele kwestii związanych z dziennikiem (volume), jak w Dz.U. 1918 nr 2 poz. 2.

    Wykaz roku¶

    dataset/acts/DU/1918.jsonl, jedna linia na akt, posortowana według pozycji:

    {"address":"WDU19180020002","announcementDate":"1918-02-04","changeDate":"2024-03-14T21:22:56","displayAddress":"Dz.U. 1918 nr 2 poz. 2","pos":2,"promulgation":"1918-02-06","publisher":"DU","status":"uznany za uchylony","textHTML":true,"textPDF":true,"title":"Ustawa o Radzie Stanu Królestwa Polskiego","type":"Ustawa","volume":2,"year":1918,"ELI":"DU/1918/2"}
    Pole Znaczenie
    ELI, address, displayAddress trzy wyżej wymienione nazwy
    publisher, year, pos, volume dziennik, rok, stanowisko, numer wydania
    title, type tytuł i typ document_types.json
    status od statuses.json, na przykład obowiązujący, uchylony
    announcementDate data samego aktu
    promulgation data publikacji w dzienniku
    changeDate kiedy zapis został ostatnio zmieniony u źródła
    textPDF, textHTML które teksty istnieją. Zbieracz im ufa.

    Znaczenie tych dwóch dat jest tym, jak czytam dane, a nie czymś, co opisała mi dokumentacja API. (zakładane)

    Szczegóły aktu¶

    bucket/DU/1918/WDU19180020002.json powtarza pola wykazu i dodaje, między innymi:

    Pole Znaczenie
    inForce IN_FORCE, NOT_IN_FORCE lub nieznane
    entryIntoForce, validFrom data rozpoczęcia stosowania aktu
    releasedBy który wydał go, od institutions.json
    authorizedBody, obligated instytucje uprawniają lub zobowiązują (zakładane)
    keywords, keywordsNames tematy i nazwiska wymienione
    texts każdy plik tekstowy, który ma źródło: fileName oraz type
    references powiązania z innymi aktami, w postaci idów, pogrupowane według rodzaju
    prints Odciski z Sejm.
    directives Dyrektywy europejskie
    previousTitle wcześniejsze tytuły

    texts wymienia każdy plik tekstowy aktu. API dokumentuje pięć typów i nie mówi, co oznaczają litery:

    Rodzaj Co to jest? Zachowane jako
    O opublikowany tekst. Ten sam plik co text.pdf (porównywany bajt dla bajtu na DU/1918/2) <address>.pdf
    H tekst HTML <address>.html
    I w aktach rozpatrzonych, ta sama nazwa pliku, co O nie dwa razy
    T kolejne PDF, nazwane jak D20260001L.pdf <address>.T.pdf
    U kolejne PDF, nazwane jak D20260001Lj.pdf <address>.U.pdf

    Na stronie internetowej ISAP te same trzy pliki są oferowane jako "tekst ogłoszony", "tekst aktu" i "tekst ujednolicony". Jeśli U jest ostatnim z nich, jest to sformułowanie aktu z późniejszymi poprawkami pracowanymi przez urząd z dnia Sejm: nie jest to oficjalny tekst, a najbardziej przydatny do czytania prawa w jego obecnym kształcie.     Struktura¶

    bucket/DU/2024/WDU20240001907.struct.json jest szkielet tekstu HTML: drzewo części, rozdziałów, artykułów, akapitów i punktów, każdy z id takie jak chpt_1-arti_1-pint_2. API daje go tylko dla czynów, które mają HTML; dla innych odpowiada 404.

    Te same identyfikatory adresują jedną jednostkę tekstu u źródła (/acts/DU/2024/1907/struct/{path}). To nie zostało zebrane: cały HTML już posiada każdą jednostkę.

    Odniesienia¶

    bucket/DU/1918/WDU19180020002.references.json jest tym samym zestawem powiązań z innym aktem opisanym w całości:

    {
    "Akty wykonawcze": [
        { "act": { "ELI": "DU/1918/20", "title": "Rozporządzenie Ministra Sprawiedliwości ...", "status": "bez statusu" } }
    ],
    "Uchylenia wynikające z": [
        { "act": { "ELI": "DU/1918/23", "title": "Orędzie Rady Regencyjnej do Narodu Polskiego" }, "date": "1918-10-21" }
    ]
}

    Klucze są rodzaje z reference_types.json: podstawa prawna, zmiany, uchylenia, akty wykonawcze, teksty skonsolidowane, orzeczenia Trybunału Konstytucyjnego i inne. Razem odniesienia do wszystkich aktów są wykresem: który akt zmienia, uchyla lub wykonuje które. Powyższe przykłady są skrócone.

    Teksty¶

    • PDF jest opublikowanym tekstem. Przez stare lata jest to skan wydrukowanego dziennika.
    • HTML istnieje tylko dla niektórych aktów. Na liście 2026 z 1321 aktów nie było tego (sprawdzone na 2026-10-13).

    HTML zmienia się w markdown przez task text. task text -- --pdf odczytuje również warstwę tekstową PDF każdego aktu bez HTML (faza 12, PP2): 125,759 z 165,006 aktów. Patrz przetwarzanie.

    Kontrole¶

    Patrz Kontrola.

    Co to jest?¶

    • Kopia oficjalnego źródła. Każdy plik ma adres pod api.sejm.gov.plKażdy może porównać naszą kopię z oryginałem.
    • Zdjęcie. Plik zawiera to, co powiedział informator w dniu jego zebrania. changeDate w wykazie pokazuje, kiedy źródło ostatnio zmieniło rekord; lista nowsza niż plik szczegółów oznacza, że szczegóły mogą być nieaktualne.
    • Unchanged. JSON jest zapisywany w odpowiedzi (sformatowane zakładkami) oraz PDF i HTML bajtów dla bajtu.

    Co to nie jest¶

    • Nieformalne porady prawnei nie jest to oświadczenie obowiązujące dzisiaj. Akt oznaczony obowiązujący mogły być wielokrotnie zmieniane; opublikowany tekst aktu jest tekstem dnia jego opublikowania. Obecne brzmienie statutu znajduje się w jego najnowszym skonsolidowanym tekście (tekst jednolity) oraz zmiany po nim.
    • Niekompletna historia. Dziennik Ustaw nie ma lat od 1940 do 1943. Prawo partycji przed 1918, lokalne prawo i oficjalne dzienniki ministerstw nie są tutaj.
    • Nie jedyne prawo w Polsce. Prawo Unii Europejskiej, ratyfikowane traktaty opublikowane gdzie indziej, a orzeczenia sądowe są poza tymi dwoma czasopismami.

    Prawa do treści¶

    Polskie prawo autorskie nie obejmuje aktów normatywnych i dokumentów urzędowych (art. 4 ustawy z dnia 4 lutego 1994 r. o prawach autorskich i pokrewnych), dlatego teksty aktów mogą być kopiowane i udostępniane. Jest to moje czytanie, a nie (formalne) porady prawne; warunki samego API nie zostały nigdzie zapisane. [TODO: potwierdzenie warunków ze źródłem]

    Osoby wymienione w aktach¶

    Akty prawne są publiczne, a niektóre nazwy osób prywatnych: Monitor Polski publikuje, na przykład, decyzje dotyczące dekoracji państwowych. Projekt lusterka działa bez zmian i buduje nic, co gromadzi osoby w różnych aktach.
