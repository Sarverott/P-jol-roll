    2026-11-24 · Cleo · phase 36: the code of law analysed, a bubble, proposals¶

    • The analysis needs no model: 165,006 acts, 750 thousand ties, 2 s. Of 23,238 acts in force: 1,064 stand on a repealed basis, 2,678 refer to a repealed act, 153 wait for a consolidated text, 42 Tribunal judgments were followed by no amendment. Amending acts were most of the noise at first (their own references are spent) - left out.
    • The text in the dataset is the act as published: the Banking Law of 1997 spoke of state banks and a Minister of the State Treasury. The law in force is its newest consolidated text, an act of its own (here DU/2026/38): the bubble and the proposals read that one now.
    • ministral-3:8b: good voices for the bubble, but an explainer instead of proposals; qwen3:8b followed the numbered findings, once each, after the task was said again at the end of the prompt and the basis limited to the findings or the text (it had invented "Dz. U. 2025 poz. 1234").
    • A small model breaks its JSON with quotes inside a post: JSON mode of Ollama's /v1 asked for, and the fields read one by one when it still breaks.

    2026-11-24 · Cleo · phase 34: the advanced strategy, the Python stack¶

    • The weak answer is judged by what can be checked, not by a model: it said nothing, cited nothing, or cited an act it did not open. The checks of phase 31 show it would catch llama (three answers of five cite nothing) and deepseek-r1:8b's unread citations; it would not catch broken Polish - the team's translator does that.
    • The large one gets the small one's answer as a draft to check, and its own first round (the nearest acts read) as every model does: the acts are read again through MCP (local, cheap), only tokens cost there.
    • mcp 2.3 for Python differs from the 1.x of most examples (the almanac, models.md). It needs httpx2, so the stack uses that one http library.

    2026-11-13 · Cleo · the git hooks never blocked anything¶

    @go-task/cli 3.45.4 runs the task binary and throws its exit code away (run-task.js calls run("task") and ends with 0). Every hook goes npm run tasks:husky → that wrapper, so a failed Biome check in pre-commit printed its errors and the commit went on anyway - since the hooks were made. 3.54.0 ends with process.exit(code).

    npm audit fix had moved the package back to 3.45.4 to leave basic-ftp (through proxy-agent, used by its installer to download the binary) behind. The range is now ^3.54.0: hooks that block are worth more than an advisory in a downloader that runs once, at install, against GitHub's releases. npm audit says 39 (8 high) after it; the new high ones are basic-ftp and its chain inside that installer.

    Checked: a bad commit message and a badly formatted staged file both stop the commit now (exit 201); a good message passes.
