    P_JOL_ROLL - Documentation¶

    Polish Journals of Laws resources operational lurker loader - complex set of tools to handle datamining, crawling and parsing of all law documents released as published by polish goverment national legal code, package of approved acts or available constitution version

    The idea¶

    Every act published in Dziennik Ustaw (since 1918) and Monitor Polski (since 1930), taken from the open ELI API of Sejm and kept in the open: raw files in a bucket, tables and markdown in a dataset on Hugging Face. Every file can be checked against its checksum, every act is tied to the acts it changes, to the work of Sejm that made it and to the judgments that apply it. The far goal is a small model and an agent that read all of it: an open devil's advocate for every person (vision).

    Not (formally) legal advices. See what the data is and is not.
