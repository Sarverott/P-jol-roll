    Магістр права¶

    Перший голос оволодіння законами (фаза 30; план власника в Q18): питання за словами, відповідь на модель, яка прочитає дії за допомогою власних MCP інструментів проекту та цитує кожну дію на його ELI. Не (формально) юридичні консультаціїЯкщо ви хочете, щоб ви зрозуміли, що ми можемо допомогти вам.

    Як це відповідей¶

    1. Акти, що знаходяться поблизу значення. Питання стає вектором моделі, що зробили вектори task embed (bge-m3), і інструмент MCP search_meaning З кожним роком порівнює його з вектором.
    2. Наші тексти Тексти найближчої триact_text) читати і надати моделі з питанням.
    3. Rounds. Модель може викликати будь-який інструмент - act, act_text, search_acts, search_meaning, ... - за шістдесяти раундів, потім відповідей.
    4. Ревізити перевіряють. Всі [DU/<year>/<position>] Відповідає відповідь read коли модель відкрита, що діє через інструмент і не читати коли він назвав його з пам'яті.

    На цій машині: хост Оллама¶

    Розробка використовує Ollama of the host (Оллама)http://127.0.0.1:11434) і його GPU, з deepseek-r1:8b і bge-m3 затягувати в неї:

    task mastermind:ask -- "Kto płaci podatek dochodowy od osób fizycznych?"
task mastermind:ask -- --json "..."        # with the reasoning and the tools it called
MASTERMIND_URL=http://127.0.0.1:11434 task serve
curl -G http://127.0.0.1:8080/api/ask --data-urlencode "question=..."

    На іншій машині: складання¶

    Профіль mastermind приносить все як контейнери: llms-ollama, llms-models (знімає моделі один раз, потім закінчується), і mastermind - зображення webapp-сервера з набором mastermind, порція /api/ask, /mcp і глядачеві 127.0.0.1:8081.

    task resources:pull -- dataset             # the acts and their vectors (dataset/embeddings/)
task mastermind:up                         # the GPU given to Ollama when nvidia-smi answers
docker compose logs -f llms-models         # the first start downloads about 6 GB
curl -G http://127.0.0.1:8081/api/ask --data-urlencode "question=..."
task mastermind:down

    Поруч: docker compose --profile mastermind up -dй -f compose.yaml -f resources/services/gpu.yaml до --profile для карток NVIDIA (для них потрібен інструментарій для контейнерів NVIDIA).

    The advanced strategy: a deepseek hosted by Hugging Face¶

    The owner's plan (Q18, phase 34): small models on the host first, the hard questions to a large deepseek hosted by Hugging Face. src/mastermind/strategy.ts:

    • --escalate: the usual model answers first; its answer goes on when it is weak - it says nothing, cites no act, or cites an act it never opened. The large one, deepseek-ai/DeepSeek-R1-0528 through Inference Providers (https://router.huggingface.co/v1; novita, deepinfra and featherless-ai serve it), gets the small one's answer to check, never to trust, and reads the acts itself through the same MCP tools.
    • --hard: straight to it.
    task mastermind:ask -- --escalate "Czy mogę odliczyć ulgę na dziecko po rozwodzie?"
task mastermind:ask -- --hard "..."
curl -G http://127.0.0.1:8080/api/ask --data-urlencode "question=..." -d escalate=1

    Here it is paid by HF_TOKEN з .env - the owner's own, so only a question the owner asks spends it; on the space by the signed-in visitor's token. The chat shows a switch a hard question when the host can pay for it (hard з /api/ask/about), and folds what the smaller model said first. The large one's conversation is kept with escalated: the small model, why its answer went on, what it said and where that is kept.

    Сортування Зареєструватися Що це таке
    HARD_MODEL deepseek-ai/DeepSeek-R1-0528 the model of hard questions
    HARD_URL https://router.huggingface.co/v1 JavaScript licenses API Веб-сайт Go1.13.8
    HARD_KEY HF_TOKEN the token it is paid by

    Not yet seen answering for real: Inference Providers refuse the owner's token with 402 until it has credits (phase 32); it is tested against a stand-in of them.

    The Python stack¶

    The models and the simulations have a stack of their own (phase 34): stacks/python/, a uv project reading the law through the same MCP tools (Law) and asking the mastermind through /api/ask (Mastermind). task python:check, task python:law -- nearest "obowiązek szkolny".

    The executive agent¶

    Not a chat but a task (phase 33): a small qwen does what a person gives it, reading the law through the MCP tools, and writes what it is asked for into resources/agent/ - the only place it can write; it runs no command and fetches no page.

    task agent -- "Przeczytaj dekret DU/1919/147 i zapisz w pliku obowiazek-szkolny-1919.md streszczenie"
task agent:container -- "..."     # the same in the agents' shell, with Ollama of the profile llms

    Its first real task, on this machine: it read the school decree of 1919 and wrote resources/agent/obowiazek-szkolny-1919.md - school age from 7, seven years of school, to 14 - citing the articles, the act marked read. Every run is kept as a conversation (resources/conversations/qwen/...).

    Two engines (AGENT_ENGINE):

    • own (the default): the mastermind's rounds with the MCP tools given directly, and one tool of its own, write_note (a bare file name, markdown, never outside resources/agent/); its instructions are resources/configs/mastermind/executive.md.
    • opencode: opencode 2 as its host, as planned, from resources/configs/agentic-shell/opencode/ - its own config and data directories (resources/.containerdatavol/agent/), so neither the person's opencode settings nor sessions are touched, --standalone, a model of its own with a 24k context. Not yet reliable: opencode 2 hands an MCP server's tools over through Code Mode, and in some runs it does not find the server's namespace (Unknown tool 'p-jol-roll.act_text').
    Сортування Зареєструватися Що це таке
    AGENT_MODEL qwen3:8b the model
    AGENT_OLLAMA_URL http://127.0.0.1:11434/v1 its Ollama (http://llms-ollama:11434/v1 in the shell)
    AGENT_ENGINE own own або opencode
    AGENT_ROUNDS, AGENT_CONTEXT 8, 24576 rounds of tools (own); context of its model (opencode)

    Оллама на власний диск¶

    Моделі великі і багато, тому Оллама цієї машини зберігає їх на приводі власних: OLLAMA_MODELS в .env (змінна Ollama сама читає) імена каталогу.

    task ollama:where        # where they are read from, and how many are there
task ollama:serve        # the first start copies ~/.ollama/models there, then serves from there
task ollama:copy         # the copy again: only what is missing, then checked

    Старий каталог ніколи не видаляється ними. Стоп Оллама, який проходить спочатку (ss -ltnp | grep 11434 Показати його. Привід, кореня якого належить до кореневих потреб своїх каталогів: task ollama:serve каже sudo line.

    Затримані розмови¶

    Кожне питання зберігається з все, що говориться, тому моделі та сім'ї можуть бути в порівнянні:

    resources/conversations/<family>/<instance>/<UNIXUSAT>-<the question's first words>.json
resources/conversations/deepseek/deepseek-r1-8b/1795498362594-czym-byla-rada-stanu-w-1918-roku.json

    Сім'я приходить resources/configs/mastermind/families.yaml (моделі однієї сім’ї виступають однією командою: gemma4, translategemma, embeddinggemma, shieldgemma... всі gemma); екземпляр - модель з його розміром. У файлі є питання, відповідь, причина, дії цитуються, інструменти, які називаються, як довго він взяв і весь обмін - тексти, надані і які інструменти відповідають. Каталог - локальна сторона власних даних, Apokryf/Consiliariis-Polonicum-Lex (conversations з resources/.map.json): task resources:push -- conversations Відправляється, що новий, людина рухається; git зберігає тільки свою картку. MASTERMIND_KEEP=0 нічого не зберігає. У складанні це один довідник, написаний майстром.

    Команди¶

    resources/configs/mastermind/families.yaml імена сімей та їх команд: одна модель відповідей, один викликає інструменти в раундах, він перетворює відповідь, надану іншою мовою в питання, одна опіка (і вирок зберігається, нічого не відбулося назад). Модель дається мислення і інструменти тільки тоді, коли Ollama каже, що це може прийняти їх.

    MASTERMIND_TEAM=gemma task mastermind:ask -- "..."   # gemma4 answers, functiongemma calls tools,
                                                     # translategemma translates, shieldgemma guards
task mastermind:compare                              # every team, the questions of questions.yaml
task mastermind:compare -- bielik qwen               # only these
task resources:push -- conversations                 # what they said, to their dataset

    На демо-просторі: власне відвідувача Hugging Face¶

    Вкладка запитати закон глядача#ask) є однодумцем як чат: кожен цитований акт посилання на його сторінку, акти його названі без читання їх позначені ?, його причина складена.

    На демо-просторі (фазі 32) він працює на власній рахунку відвідувача, так як інший простір власника робить: карта простору просить за hf_oauth з обсягом inference-api, знаки відвідувачів з Hugging Face (/login), і токен залишається в пам'яті сервера за допомогою HttpOnly cookie - він ніколи не досягає браузера, файлу або журналу. Далі:

    • модель за допомогою Inference Providershttps://router.huggingface.co/v1), google/gemma-4-26B-A4B-it за замовчуваннямDEMO_MODEL; DEMO_URL за інші api), сплачені від зарахування відвідувачів;
    • питання вектора BAAI/bge-m3 на Hugging Face, однакова модель, як і вектори набору даних, яка займає простір на першому місці (близько 760 Мб);
    • Одне питання в часі відвідувача, чотири одночасно, розмова відвідувача не зберігається.

    Відвідувач без кредитів, що залишилися, отримує Hugging Face власну відповідь: "Purchase pre-paid credits to continue using Inference Providers". Простірні знаки без hf_oauth в картці, /api/ask потім каже так.

    Сортування Зареєструватися Що це таке
    DEMO_MODEL google/gemma-4-26B-A4B-it модель на простір
    DEMO_URL https://router.huggingface.co/v1 JavaScript licenses API Веб-сайт Go1.13.8
    OAUTH_CLIENT_ID, OAUTH_CLIENT_SECRET, OPENID_PROVIDER_URL, SPACE_HOST набір Hugging Face Реєстрація

    Що чекати¶

    deepseek-r1:8b on an RTX 3060 answers in 30 seconds to a few minutes, most of it thinking. It is the smallest voice of the plan: it now and then answers in English, slips a word of another script into Polish, or cites an act it did not open - which the check marks. The larger deepseek of phase 34 (the advanced strategy above) is for the hard questions.
