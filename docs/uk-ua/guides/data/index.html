    Дані¶

    Усі зібрані землі resources/, в двох місцях з двома роботами.

    resources/
├── dataset/                    tables: small, read often
│   ├── lists/
│   │   ├── index.json          what the API offers, with addresses
│   │   ├── publishers.json     journals with their years and counts of acts
│   │   ├── statuses.json       every status an act can have
│   │   ├── document_types.json every type of act (Ustawa, Rozporządzenie, ...)
│   │   ├── reference_types.json every kind of tie between acts
│   │   ├── keywords.json
│   │   └── institutions.json
│   ├── acts/<journal>/<year>.jsonl        metadata, one act per line
│   ├── files/<journal>/<year>.jsonl       checksum and source of every gathered file
│   ├── details/<journal>/<year>.jsonl     details of acts, put together by compile
│   ├── references/<journal>/<year>.jsonl  ties between acts, one per line
│   ├── texts/<journal>/<year>.jsonl       which markdown was made from which HTML
│   ├── texts/<journal>/<year>/<address>.md  the text as markdown
│   └── checkups/<journal>/<year>.jsonl    what the browser saw, one visit per line
└── bucket/                     raw files of every act
    └── <journal>/<year>/
        ├── <address>.json              details
        ├── <address>.references.json   ties to other acts
        ├── <address>.pdf               the published text
        ├── <address>.html              the text as HTML, for some acts
        ├── <address>.struct.json       parts, chapters, articles of the HTML text
        └── <address>.T.pdf, .U.pdf     other texts of the act

    Столи files, details, references і texts описуються в з сирих файлів до таблиць і текстів. Робота Sejm та судових рішень мають власні каталоги: див. інші джерела.

    <journal> Про нас DU або MP. <address> є ідентифікатором API дає кожному акту, наприклад, WDU20260000001.

    Як називається акт¶

    Ім'я Приклад Використовується для
    ELI DU/2026/1 адреси API: журнал, рік, позиція
    Контакти WDU20260000001 імена файлів; ідентифікатор, що використовується ISAP
    адреса відображення Dz.U. 2026 poz. 1 як юристи цитують його

    Старі дії також мають ряд питань журналу (volume), як в Dz.U. 1918 nr 2 poz. 2.

    Список року¶

    dataset/acts/DU/1918.jsonl, один рядок за акт, відсортований за посадою:

    {"address":"WDU19180020002","announcementDate":"1918-02-04","changeDate":"2024-03-14T21:22:56","displayAddress":"Dz.U. 1918 nr 2 poz. 2","pos":2,"promulgation":"1918-02-06","publisher":"DU","status":"uznany za uchylony","textHTML":true,"textPDF":true,"title":"Ustawa o Radzie Stanu Królestwa Polskiego","type":"Ustawa","volume":2,"year":1918,"ELI":"DU/1918/2"}
    Сфера Малювання
    ELI, address, displayAddress три імена вище
    publisher, year, pos, volume журнал, рік, позиція, кількість випуску
    title, type назва та тип з document_types.json
    status з statuses.jsonНаприклад, obowiązujący, uchylony
    announcementDate дата дії
    promulgation дата публікації в журналі
    changeDate коли запис було оновлено на джерело
    textPDF, textHTML які тексти існують. Збирач довіряє ці

    Значення двох дат є те, як я прочитав дані, а не те, що документація API повідомила мене. (примушені)

    Деталі акції¶

    bucket/DU/1918/WDU19180020002.json повторює поля переліку та додає, серед інших:

    Сфера Малювання
    inForce IN_FORCE, NOT_IN_FORCE чи невідомо
    entryIntoForce, validFrom дати акту почав застосовувати
    releasedBy хто видав його, від institutions.json
    authorizedBody, obligated установ, які діють повноваження або зобов'язання (примушені)
    keywords, keywordsNames суб'єктів і імен
    texts кожен текстовий файл має: fileName і type
    references зв'язки з іншими діями, як ids, груповані за типом
    prints друкує Sejm акт прибув
    directives Європейська директива провадить
    previousTitle раніше назв

    texts списує кожен текстовий файл акту. API документи п'ять типів і не говорять про те, що листи означають:

    Тип Що це таке Кепт як
    O опублікований текст. Який файл text.pdf (зварений байт для байту на DU/1918/2) <address>.pdf
    H HTML текст <address>.html
    I в діях дивився на той же ім'я файлу як O не приймати двічі
    T ще PDF, названий як D20260001L.pdf <address>.T.pdf
    U ще PDF, названий як D20260001Lj.pdf <address>.U.pdf

    На веб-сайті ISAP пропонуються такі ж три файли, як "tekst ogłoszony", "tekst aktu" та "tekst ujednolicony". Якщо U є останнім з них, це слово дії з пізніми змінами, які працювали в офісі Sejm: не офіційний текст, а найкорисніший для читання закону, як він стоїть. (з імен файлів; не підтверджено) [TODO]

    Структура¶

    bucket/DU/2024/WDU20240001907.struct.json є скелетом HTML тексту: дерево деталей, розділів, статей, абзаців і точок, кожен з id як chpt_1-arti_1-pint_2. API дає йому тільки дії, які мають HTML; для інших це відповідей 404.

    Те ж самі ids адреси одного блоку тексту на джерело (/acts/DU/2024/1907/struct/{path}). Це не зібрано: весь HTML вже тримає кожну одиницю.

    Посилання¶

    bucket/DU/1918/WDU19180020002.references.json є тим самим набором зв'язків, з іншим актом, описаним в повній мірі:

    {
    "Akty wykonawcze": [
        { "act": { "ELI": "DU/1918/20", "title": "Rozporządzenie Ministra Sprawiedliwości ...", "status": "bez statusu" } }
    ],
    "Uchylenia wynikające z": [
        { "act": { "ELI": "DU/1918/23", "title": "Orędzie Rady Regencyjnej do Narodu Polskiego" }, "date": "1918-10-21" }
    ]
}

    Ключові слова: reference_types.json: правова основа, зміни, репетиції, виконавчі акти, консолідовані тексти, ухвали Конституційного суду та інші. Разом з довідниками всіх актів є граф: які діють зміни, повтори або проваджені які. Приклади вище загинаються.

    Тексти¶

    • PDF опублікований текст. За останні роки це сканування друкованого журналу.
    • HTML існує тільки для деяких дій. У списку 2026 не було 1321 актів (звернуто на 2026-10-13).

    HTML перетворюється в markdown by task text. task text -- --pdf також читає текстовий шар PDF кожного акту без HTML (фаза 12, PP2): 125,759 165,006 актів. Про нас обробка.

    Що це таке¶

    • Копія офіційного джерела. Кожен файл має адресу api.sejm.gov.pl, щоб кожен може порівняти нашу копію з оригінальною.
    • Пробити Файл має те, що джерело, зазначене в день, він був зібраний. changeDate в списку показів, коли джерело останнього змінив запис; список нових, ніж файл деталей означає, що деталі можуть бути з дати.
    • Unchanged. JSON зберігається, як це було відповів (форматований з вкладками), і PDF і HTML байт для байтів.

    Що це не¶

    • Не (формально) юридичні консультації, а не заява закону про чинність сьогодні. Визначений акт obowiązujący може бути змінено багато разів; опублікований текст акту є текстом дня, який був опублікований. Поточне слово статуту в його новітній консолідований текстtekst jednolity) і зміни після цього.
    • Не повна історія. Dziennik Ustaw років 1940 до 1943. Законодавство перегородок до 1918, місцевого законодавства та офіційних журналів міністерств не є тут.
    • Не єдиний закон, який діє в Польщі. Право Європейського Союзу, ратифіковані договори опубліковані в іншому місці та ухвали суду поза цими двома журналами.

    Права на зміст¶

    Польське право авторського права не охоплює нормативні акти та офіційні документи (частина 4 акту 4 лютого 1994 про авторські права та суміжні права), тому тексти актів можуть бути скопійовані та поділені. Це мій читання і не (формально) юридичні консультації; умови API себе не знайшли написаних в будь-якому місці. [TODO: підтвердити умови з джерелом]
