    Функції¶

    Кожна функція проекту і кожен спосіб його роботи - написана task functions:map з каталогуsrc/core/catalog/procedures.ts), щоб не редагувати його вручну. Стартер (баре) task), його РЕПЛА та task do пропонує кожну функцію; інші способи, де імена комірок. На цій машині стартує функція запису (викладач) і api тільки на цій машині, коли api працює з --allow-writing (додаток на робочий стіл), кожен після того, як людина так; громадський хост показує його вимкнено (Q19). – є отвір.
