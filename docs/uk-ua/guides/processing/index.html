    З сировини до таблиць і текстів¶

    task seal                 # checksums for gathered files that have no record yet
task seal -- --check      # read every recorded file again, name the ones that differ
task compile              # tables: details and references of acts, a year in a file
task text                 # markdown from gathered HTML, with checksums
task text -- --pdf        # and from the PDFs of acts without HTML (poppler-utils)

    В інтернеті немає нічого. Прочитати resources/bucket/ і писати resources/dataset/У будь-який час можна повторити.

    Checksums: seal¶

    Відро на Hugging Face не дає дозволу файлу, тому проект зберігає свій власний. Один рядок за файл в dataset/files/<journal>/<year>.jsonl:

    {"path":"DU/1918/WDU19180010001.json","size":3578,"sha256":"0c1f2c7e...","url":"https://api.sejm.gov.pl/eli/acts/DU/1918/1","gatheredAt":"2026-10-13T13:25:12.282Z"}
    Сфера Малювання
    path файл, всередині відро
    size, sha256 як було написано
    url де було прийнято
    gatheredAt коли

    Збирач пише запис в даний момент на диску, перш ніж все надішло. task seal є для файлів, зібраних до записів існував: він пише відсутні записи, з часом модифікації файлу, як gatheredAt.

    task seal -- --check читати кожен записаний файл, який тут і порівнює. Видрукує доріжки, які відрізняються і закінчується помилкою, коли є будь-які. Виконайте його після витягування відра в іншу машину, або перед великим штовхачем.

    Коли файл має кілька записів, останній є струмом.

    Tables: compile¶

    Деталі та посилання, що сидять у відрі, як один невеликий файл за актом. Для читання на сипучих носіях, рік у файлі:

    Настільний Один рядок Виготовлений з
    dataset/details/<journal>/<year>.jsonl деталі одного акту, як API дав їм <address>.json
    dataset/references/<journal>/<year>.jsonl одна краватка між двома діями Промисловість references Деталі

    Лінія таблиці посилань:

    {"from":"DU/1918/2","type":"Uchylenia wynikające z","to":"DU/1918/23","date":"1918-10-21"}
    Сфера Малювання
    from ELI акту, деталями яких назвали краватку
    type вид краватки, від lists/reference_types.json
    to ELI іншої дії
    date, art присутній, коли API дає їм

    Всі довідкові таблиці разом є графіком закону: які діють зміни, репетиції або провадять які. Перші шістьнадцять років Dziennik Ustaw дають 45,658 зв'язків за 11,008 актів.

    Акти, які деталі не збираються, але поки не вийшли. Столи письмові на кожен пробіг.

    Texts: text¶

    Зібрано HTML файла markdown, dataset/texts/<journal>/<year>/<address>.mdі лінія в dataset/texts/<journal>/<year>.jsonl стяжки до джерела:

    {"ELI":"DU/1918/2","markdown":"texts/DU/1918/WDU19180020002.md","sha256_md":"a85ee287...","sha256_html":"1fd223bc...","url":"https://api.sejm.gov.pl/eli/acts/DU/1918/2/text.html"}
    Сфера Малювання
    markdown markdown файл, всередині даних
    sha256_md від markdown
    sha256_html checksum від HTML він був виготовлений з
    url HTML на джерело

    HTML, чия реєстрація не змінилася знову не приурочена.

    Як виглядає markdown:

    # Ustawa z dnia 4 lutego 1918 r. o Radzie Stanu Królestwa Polskiego

## Treść ustawy

### Art. 1.

Rada Stanu Królestwa Polskiego z siedzibą w mieście stołecznem Warszawie składa się ze 110 członków, a mianowicie:

a) 12 członków wirylistów,

    Статті, абзаци§Український переклад І. Огієнка Відкрийте свою лінійку. Видалено сценарії та кнопки зчитувача Sejm.

    Про нас markdown дивився лише на дії від 1918 до 1933. Нові дії можуть використовувати HTML цього сердечника, а таблиці не перетворюються в markdown таблиці. Прочитайте кілька нових, перш ніж довірити його на об'ємі.

    Тільки HTML подається: 39,110 з 164,638 актів, всі в Dziennik Ustaw. На другий три чверті мають лише PDF і більше markdown.

    Порядок роботи¶

    gather ──► seal (once, for old files) ──► compile ──► text ──► resources:push

    Тексти PDF¶

    task text -- --pdf дає markdown діям, які мають лише PDF. Текстовий шар читайте pdftotext з попплераscripts/install.sh монтаж poppler-utils), що випливає з двох стовпчиків сторінки журналу. Лінії стають абзаци, слово нарізають в кінці рядка приклеюють назад, і Art. 1., § 1. і Rozdział 1 стають заголовками, як в markdown від HTML. Чотири PDF-файли читаються в часі (--parallel); рік 1200 актів займає кілька секунд.

    Більшість PDF-файлів перед 2000-ма скануванням, що Adobe's Paper Capture дав шар визнаного тексту. Тексти пісень, а це означає: Це текст зберігається як це, з його помилками: нічого виправити, здогадуючи. Запис імен виробника PDF, тому читач може розповісти ці тексти окремо:

    {"ELI":"DU/1953/228","markdown":"texts/DU/1953/WDU19530460228.md","sha256_md":"...","from":"pdf","sha256_pdf":"...","producer":"Adobe Acrobat 9.0 Paper Capture Plug-in","url":"https://api.sejm.gov.pl/eli/acts/DU/1953/228/text.pdf"}

    А PDF без текстового шару (підйомка, ніж 40 літер на всіх сторінках, близько сто) не отримує markdown; вона названа в dataset/texts/<journal>/<year>.scans.jsonl і чекає на ОКР. Коли дія отримує свою HTML пізніше markdown з HTML знову.

    Без категорії --pdf, task text зберігає тексти з PDF, як вони.

    Читачі кажуть, що тексти це: акт в api має text.from (html або pdf) за адресою виробника та джерела, відповідь /api/acts/<journal>/<year>/<pos>/text здійснює заголовок X-Text-From, інструмент MCP act_text Відкриває такий текст із рядком, що нагадує його PDF, а глядач накладає замітку над ним.

    Карта всього закону: map¶

    task map                        # every preset into dataset/map/
task map -- statutes-in-force   # one

    Всі 165 тис. актів з 750 тис. зв'язків занадто багато для сторінки, тому припуск бере участь в них, з зв'язками між діями від dataset/references/:

    Зареєструватися Акції Цій (2026-11-22)
    statutes-in-force statutes (ustawy) в силі 2,848 / 2,234
    statutes з 1918 9,985 / 71,489
    in-force кожен акт в силі 20,484 / 11,953
    statutes-in-force-by-meaning статути, які мають вектор (task embed), кожен прив'язаний до свого 5 найближчого значення замість зв'язків джерела як багато векторів

    ForceAtlas2 розміщує їх один раз, тут (близько хвилини для всіх трьох), тому браузер тільки малює: вкладка "map of the whole law" глядача показує їх з sigma.js, /api/map/<preset> дає їм. Пробіг task compile перше, тому стяжки свіжі. Файли переходять до Hugging Face з даними, тому демо може показати їх.

    Пошук за кожним роком: search:index¶

    task init                                         # once: resources/secrets/typesense_api_key
docker compose --profile search up -d typesense   # Typesense 30.2 on 127.0.0.1:8108
task search:index                                 # titles, types, statuses, keywords
task search:index -- --texts                      # and the first 2000 characters of each text

    Кожен акт надходить в колекцію acts (в дії вже є замінено). Заголовки, ключові слова та тексти кенуються як польською. Відповіді api /api/search?q=...&type=&status=&journal=&page= з актами, позначеними словами їх текстів та підрахунками на тип, статус та журнал. Відповіді на пошук. Без Typesense, /api/search Відповіді 503 і каже, як його запустити, і нічого іншого зміни. Всі 165 тис. актів приймають 10 секунд; з текстами 20 секунд і близько 450 Мб пам'яті в сервісі.

    Вектори текстів: embed¶

    ollama serve &              # or: docker compose --profile llms up -d llms-ollama
ollama pull bge-m3          # once, about 1.2 GB
task embed                  # every text; task embed -- 2026 for one year

    Кожен акт з markdown отримує один вектор: його назву і перші 2000 символів його тексту, враховуючи локальну багатомовну модель через Ollama (04/07/2019)EMBED_MODEL, bge-m3 за замовчуванням: 1024 номерів, польські мови. Тексти пісень, а це означає: Вони йдуть біля текстів, в dataset/embeddings/<model>/<journal>/<year>.parquet (ELI, sha256_md, vectorй model.json Як вони були зроблені. Акт, чия markdown не змінив зберігає свій вектор, тому старт повторюється, щоб прийняти те, що нового.

    DU 2020 (2453 дій) приймав 1 хвилин 46 секунд на GeForce RTX {10} і 4 Мб. Всі права будуть приймати близько двох годин і 670 Мб.

    Пошук за змістом¶

    З векторами, зроблені, task search:index кладуть їх в Typesense теж (у існуючій колекції надходить поле без створення нового). Пошук кожного року з meaning=1 перетворює питання у вектор з такою ж моделлю Оллама, а Typesense р. виступає словами і за змістом разом. Питання англійською мовою знаходить польські акти: "protection of children against violence at school" знайшли акти Міністра освіти з питань безпеки у школах, де слова наодинці знайшли один акт. Без Ollama, пошук говорить meaning: false і твори слів поодинці. Переглядач показує поле "by meaning, in any language" тільки тоді, коли він може це зробити.
